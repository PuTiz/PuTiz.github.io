故宫博物院

★★★★★推荐指数 4.9分

故宫又称紫禁城，是明清两代的皇家宫殿，位于北京中轴线的中心。故宫占地面积72万平方米，建筑面积约15万平方米，有大小宫殿七十多座，房屋九千余间。 故宫是世界上现存规模最大、保存最为完整的木质结构古建筑之一，1987年被列为世界文化遗产。故宫前部宫殿，当时建筑造型要求宏伟壮丽，庭院明朗开阔，象征封建政权至高无上。 故宫的设计与建筑，是一个无与伦比的杰作，它的平面布局，立体效果，以及形式上的雄伟、堂皇、庄严、和谐，都可以说世上罕见的。主要看点包括太和殿（金銮殿）、乾清宫、御花园、珍宝馆。游览提示：建议提前在线购票，周一闭馆。实用信息：景区位于北京市东城区景山前街4号，门票旺季60元 / 淡季40元，开放时间08:30–17:00（周一闭馆）。

游览提示：建议提前在线购票，周一闭馆。游览时间约3-4小时。推荐从午门进入，神武门退出。

  • 地址：北京市东城区景山前街4号
  • 门票：旺季60元 / 淡季40元
  • 开放时间：08:30–17:00（周一闭馆）

天安门广场

★★★★★推荐指数 4.9分

天安门广场南北长880米、东西宽500米，总面积约44万平方米，是北京中轴线上的核心公共空间。广场北端的天安门城楼始建于明永乐十五年（1417年），是明清皇城正门；广场中央的人民英雄纪念碑1949年奠基、1958年落成，碑高37.94米；南侧毛主席纪念堂、西侧人民大会堂、东侧中国国家博物馆共同围合出今天的天安门广场。每天清晨的升旗仪式按日出时间举行，来自全国各地的游客会提前一小时到场。游览提示：参观需提前1–7天实名预约，带身份证原件；升旗前1小时到安检口排队。实用信息：景区位于北京市东城区东长安街，门票免费（需实名预约），开放时间05:00–22:00（升旗时间随日出变化，以官方公告为准）。建议根据开放时间与体力合理安排停留时长。

  • 地址：北京市东城区东长安街
  • 门票：免费（需实名预约）
  • 开放时间：05:00–22:00（升旗时间随日出变化，以官方公告为准）

八达岭长城

★★★★★推荐指数 4.8分

八达岭长城是明长城中保存最好、也最具代表性的地段，位于北京市延庆区军都山关沟古道北口。八达岭长城其地势险要，构筑雄伟，自古以来便是"拱卫陵京"的军事战略要地。 "不到长城非好汉"，八达岭长城是古今中外各界人士到北京游览的必到之所，迄今已接待中外游人一亿三千万余位。 八达岭长城蜿蜒于崇山峻岭之间，依山而建，气势磅礴，雄伟壮观，是万里长城向游人开放最早的地段。八达岭长城是明长城中保存最完好、最具代表性的地段，蜿蜒于军都山崇山峻岭之间，海拔1000余米，城墙坚固雄伟，自古便是"拱卫陵京"的军事要塞。"不到长城非好汉"，这里已累计接待中外游客超亿人次。主要看点包括北八楼（北八达岭）、好汉坡、望京石。游览提示：建议乘坐S2线市郊铁路前往，早起可避开人流。实用信息：景区位于北京市延庆区八达岭镇，门票旺季40元 / 淡季35元，开放时间06:30–19:00。

游览提示：建议乘坐S2线市郊铁路前往，早起可避开人流。北线较陡但风景更好，南线较缓适合老人小孩。

  • 地址：北京市延庆区八达岭镇
  • 门票：旺季40元 / 淡季35元
  • 开放时间：06:30–19:00

天坛公园

★★★★★推荐指数 4.7分

天坛是明清两代皇帝祭天、祈谷的场所，位于北京市南部，东城区永定门内大街东侧。占地约273万平方米。天坛建于明永乐十八年（1420年），清乾隆、光绪时曾重修改建。 天坛是世界上最大的古代祭天建筑群，其建筑布局和建筑手法充分体现了中国古代"天圆地方"的宇宙观。祈年殿是天坛的标志性建筑，三重檐圆殿坐落在三层汉白玉石基上，殿内结构独特，不用大梁长檩，仅用楠木柱和枋桷相互衔接支撑。主要看点包括回音壁、圜丘坛。游览提示：清晨可看到当地老人晨练、唱戏，非常有生活气息。实用信息：景区位于北京市东城区天坛内东里，门票联票34元，开放时间06:00–22:00（祈年殿等核心建筑一般08:00后开放）。最佳旅行季节：秋季（9–11月）天高气爽，香山红叶正盛；春季（4–5月）亦宜人。

游览提示：清晨可看到当地老人晨练、唱戏，非常有生活气息。建议购买联票游览核心建筑。

  • 地址：北京市东城区天坛内东里
  • 门票：联票34元
  • 开放时间：06:00–22:00（祈年殿等核心建筑一般08:00后开放）

颐和园

★★★★★推荐指数 4.7分

颐和园前身名清漪园：乾隆十四年（1749年）起疏浚瓮山泊，1750年赐名昆明湖，历经十余年至乾隆二十九年（1764年）全园建成，与静宜园、静明园、圆明园、畅春园合称京西“三山五园”。1860年清漪园被英法联军焚毁，光绪年间重建后于1888年改名颐和园；1900年再遭八国联军劫掠，1924年辟为公园对公众开放。 全园水面约占四分之三，昆明湖中的西堤仿杭州西湖苏堤而筑六桥；东堤的十七孔桥长150米、宽8米，十七个券洞两两对称，望柱上共雕石狮544只，冬至前后落日余晖可穿透全部桥洞，成“金光穿洞”一景。万寿山前山的佛香阁高41米、八面四重檐，为全园的构图核心。1998年12月，颐和园列入《世界遗产名录》。

游览提示：建议从东宫门进入，沿昆明湖畔游览。下午可在湖边看日落，非常美丽。

  • 地址：北京市海淀区新建宫门路19号
  • 门票：旺季30元 / 淡季20元
  • 开放时间：06:30–18:00

中国国家博物馆

★★★★★推荐指数 4.8分

中国国家博物馆由原中国历史博物馆与中国革命博物馆合并组建，2007年正式挂牌，2011年新馆开放。馆舍建筑面积近20万平方米，展厅48个，馆藏140余万件。镇馆之宝包括商代后母戊鼎、四羊方尊、西周利簋、汉代击鼓说唱俑等。“古代中国”基本陈列按远古到明清的时间线展开，是理解中华文明最系统的一条参观动线；“复兴之路”则聚焦近现代史。世界上单体建筑面积最大的博物馆之一，馆藏140余万件，从后母戊鼎、四羊方尊到击鼓说唱俑，一部中国通史几乎都能在这里看到。常设“古代中国”是最值得优先安排的基本陈列。主要看点包括古代中国基本陈列。游览提示：至少预留3–4小时；先看“古代中国”，再看临时展。实用信息：景区位于北京市东城区东长安街16号，门票免费（需实名预约），开放时间09:00–17:00（周一闭馆，16:00停止入馆）。

  • 地址：北京市东城区东长安街16号
  • 门票：免费（需实名预约）
  • 开放时间：09:00–17:00（周一闭馆，16:00停止入馆）

明十三陵

★★★★★推荐指数 4.6分

明十三陵是明朝迁都北京后十三位皇帝的陵墓群，散布于北京西北约50公里的昌平天寿山南麓，自永乐七年（1409年）长陵始建，延续两百余年。陵区共享一条石像生林立的神道，各陵均有独立的方城明楼与宝城宝顶。 现已对外开放的有定陵、长陵和昭陵。定陵（万历皇帝朱翊钧之陵）的地宫经过考古发掘，游客可深入地下墓室；长陵祾恩殿是现存最大的楠木殿之一，用整根金丝楠木立柱，极为壮观。2003年，明十三陵作为"明清皇家陵寝"扩展项目列入世界文化遗产。主要看点包括神路石像生、定陵地下宫殿。游览提示：各陵分散，建议自驾或乘公交（昌平线地铁转872路）串联游览。实用信息：景区位于北京市昌平区十三陵镇，门票长陵旺季45元 / 淡季30元；定陵60元 / 40元；昭陵30元 / 20元；神路30元 / 20元（联票更划算），开放时间08:00–17:00（各陵开放时间略有差异）。

  • 地址：北京市昌平区十三陵镇
  • 门票：长陵旺季45元 / 淡季30元；定陵60元 / 40元；昭陵30元 / 20元；神路30元 / 20元（联票更划算）
  • 开放时间：08:00–17:00（各陵开放时间略有差异）
